# LifeOps 日光工作台重构设计规格

## 目标

把 LifeOps 从“公开与私人共享星球世界观”的展示型原型，重构为两个边界清楚、品牌连续的产品表面：公开页负责探索与表达，私人页负责每天高效完成计划、记录、回顾、知识与发布闭环。

## 已批准方向

- 视觉世界：日光工作台（Daylight Drafting Table）。
- 构图：采用构图板 A——纵向日程主舞台 + 右侧上下文窄栏；移动端按任务优先级纵向折叠。
- 私人首页第一优先级：“今天该做什么”。
- Impeccable direction seed：`cb94c32e`。
- 构图证据：`.impeccable/sketches/lifeops-daylight-workbench-compositions.png`。

## 公开页

1. 白天默认暖白与浅蓝，19:00～07:00 默认星空黑；用户手动切换只持续到下一个时间边界。
2. 首屏最多五个内容对象：此刻、项目、笔记、时间线、公开快照。对象图形必须与内容语义一致，不使用 Docker、Kubernetes 等技术标志充当一级导航。
3. 三条可见路径与对象运动共享同一 SVG 几何源；节点持续运动但不抢文字注意力，`prefers-reduced-motion` 时静止在路径上。
4. 滚轮只执行浏览器原生纵向滚动。页面依次展示首屏、LifeOps 闭环演示、当前内容、公开快照与最终登录入口。
5. 点击对象进入独立详情页；吸附式返回栏、浏览器返回和 Escape 始终可用，返回时恢复首页滚动位置。
6. 技术栈只出现在项目详情的“技术底座”段落。

## 登录边界

- 登录成功只播放一次 700～900ms 边界转场。
- 白天：轨道线拉直为时间线与对齐网格；夜间：星光后退，中央白色光圈扩展为工作台。
- 共享 LifeOps 字标和中心焦点保持连续；私人页加载时内容默认可见，不依赖动画才能阅读。
- 减少动态模式使用不超过 120ms 的淡入。

## 私人工作台

1. 始终使用暖白/冷白背景，不继承公开页夜间主题；完全移除星球、轨道、银河和深色持续背景。
2. 不使用左侧功能栏，也不使用等大圆角卡片墙。顶部稳定导航包含：今天、计划、记录、回顾、知识、发布；右侧包含搜索、快速记录和账户。
3. 首页采用 12 列无边框画布：左侧 8 列为 06:00～22:00 日程时间线，右侧 4 列为接下来、待回顾、最近记录。
4. 高频动作首屏可达：添加计划、完成计划、快速记录、进入待回顾内容。
5. 全局搜索通过 `Ctrl/Cmd+K` 打开，搜索计划、记录、回顾、知识和快照；结果直接跳转到对应模块。
6. 各模块使用任务专属布局：计划是可执行清单，记录是时间流，回顾是证据工作台，知识是搜索优先资料库，发布是编辑/预览双栏。
7. 普通路由切换 160～260ms，稳定外壳不重复入场；仅正文按前进/后退方向移动 8～12px 并淡入。

## 功能边界

- 保留现有真实 API、MySQL、会话、CSRF、用户隔离及快照字段白名单。
- 保留完整闭环：计划 → 完成 → 记录 → 回顾 → 知识 → 选择字段生成快照 → 发布/撤回。
- 本轮增加：计划独立入口、全局搜索和快速记录；不增加未经验证的商业功能、统计指标或社交功能。

## 质量门禁

- 单元与组件测试先失败再实现；现有闭环不得回归。
- 桌面与 390px 移动端无横向溢出，核心触控目标不小于 44px。
- 键盘可完成登录、导航、搜索、快速记录、闭环和退出；焦点可见且不会逸出对话框。
- 对象轨道、滚动与路由转场以 `transform`/`opacity` 为主；无逐帧布局读写；离屏动画暂停。
- Playwright 覆盖公开自然滚动、五入口、固定返回、昼夜主题、登录转场、私人首页、全局搜索、完整闭环、移动端和减少动态。

## 非目标

- 本轮不推送 UHub、不部署 Kubernetes、不声称集群已运行。
- 不重做后端数据模型为项目/习惯系统；这些留给后续版本。
- 不复制参考站源码、品牌、素材或具体构图。
